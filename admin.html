İlk qurulum

GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token. Yalnız bu repo seçilsin, Permissions → Contents: Read and write. Token bu cihazda parolunla şifrələnib saxlanır, başqa yerə göndərilmir.

Hər sual nömrə ilə başlayır (1. 2. 3.). Variantlar A) B) C)… kimi yazılır, sonra "Cavab:" və istəsən "Həll:" gəlir. Variant yoxdursa sual açıq sual olur. Riyazi ifadələr $x^2+1$ kimi yazılır.
