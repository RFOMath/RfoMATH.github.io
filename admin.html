İlk qurulum

Token almaq üçün GitHub → Settings → Developer settings → Fine-grained tokens bölməsinə keç. Yalnız bu repozitoriyanı seç və Contents icazəsini Read and write et. Token parolunla şifrələnib yalnız bu cihazda saxlanır.

Arxiv faylları

Fayllar arxiv/ qovluğunda saxlanır. Burada yaratdığın hər qovluq saytda avtomatik bölmə olur.

Kitablar

Üz qabığı saytda kitabın şəkli kimi görünür. Şəkil yoxdursa PDF-in ilk səhifəsi göstərilir.

Hər sual nömrə ilə başlayır (1. 2. 3.). Variantlar A) B) C) kimi yazılır, ardınca "Cavab:" və istəsən "Həll:" gəlir. Variant yoxdursa sual açıq sual sayılır. Düsturlar $x^2+1$ kimi yazılır.
